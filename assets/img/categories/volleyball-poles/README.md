## Image Requirements

### Technical Specifications
- **Minimum Resolution:** 1200x800px (recommended: 1400x900px)
- **Aspect Ratio:** 16:10 or 3:2 preferred
- **Format:** JPG (optimized for web, under 200KB per image)
- **Quality:** High resolution, professional product photography

### Content Guidelines
- Show actual volleyball poles/posts in use or staged professionally
- Include proper volleyball nets when possible for context
- Outdoor images should show natural lighting and outdoor settings
- Indoor images should show gym/facility environments
- Avoid cluttered backgrounds - focus on the poles themselves
- Ensure good contrast for white text overlay readability

### CLS Prevention
All images will be loaded with proper aspect-ratio CSS to prevent Cumulative Layout Shift. Images should be optimized for fast loading while maintaining visual quality.
